# Robot or Me? — HFD Card Game

A card game and half-day workshop for children around age 10. Players decide what a helpful robot should do, and what people should still do themselves.

Part of *Human-Focused Design in the Age of AI*.

## What's here

| File | What it is |
| --- | --- |
| `index.html` | The online game. Open it in a browser and pass one device around the table. |

## The deck

| Type | Count | Role |
| --- | --- | --- |
| Scenario | 13 | The world: a magical place where a robot helps |
| Dilemma | 13 + 2 blank | The problem: two good sides, no easy answer |
| Tool card | 13 | The lens: a framework principle, as a question |
| Twist | 13 | The rule: a condition that forces a trade-off |

## How a round works

1. Draw a scenario and a dilemma.
2. Draw a twist.
3. Each player gets two tool cards and keeps one.
4. Reveal, discuss, and decide together: what the robot does, what people still do, and what we gave up.
5. Reflect: did the robot skip anything people should do themselves?
